# mochi_studio

GraphQL studio for mochi: a playground, query collections, and a visual schema explorer.

## Installation

```toml
# gleam.toml
[dependencies]
mochi_studio = { git = "https://github.com/qwexvf/mochi_studio", ref = "main" }
```
